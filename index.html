Web Engines Compare

Benchmarks comparing PlayCanvas, Three.js and Babylon.js — including different versions of the same engine, so optimizations can be measured release to release.

Tests

  • Draw Call Performance CPU submission cost: a dense grid of 10K–20K tiny cubes, each its own draw call, with a configurable number of unique PBR materials (1–1000) at three complexity levels. Identical deterministic scene and camera in every engine; MSAA off, pixel ratio 1.
Source on GitHub — engine versions are configured in engines.config.js.

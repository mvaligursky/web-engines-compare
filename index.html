Web Engines Compare

Benchmarks comparing PlayCanvas, Three.js and Babylon.js — across engine versions and graphics backends (WebGL2 and WebGPU), so optimizations can be measured release to release.

Tests

  • Draw Call Performance CPU cost: a dense grid of 1K–20K small boxes, each its own draw call, with configurable numbers of unique meshes and unique PBR materials (1–1000) at three complexity levels, and a directional light casting single-cascade shadows onto a plane behind them. Identical deterministic scene and camera in every engine, on WebGL2 and WebGPU; MSAA off, pixel ratio 1.
Source on GitHub — engine versions are configured in engines.config.js.
